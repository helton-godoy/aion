## 2025-05-18 - fs.pathExists redundancy in captureCurrentState
**Learning:** Checking `fs.pathExists` before `fs.readFile` and `fs.stat` is a performance bottleneck in `captureCurrentState` in `src/modules/aion/safety/safety-protocol.js`. We can just try to read and catch the `ENOENT` error. Since this is an internal function for taking snapshots, optimizing the I/O can improve performance, especially if many file changes are involved. Furthermore, doing so sequentially using a `for...of` loop is slow for many files. We can use `Promise.all` with mapping.
**Action:** Optimize `captureCurrentState` to remove redundant `fs.pathExists` checks by catching `ENOENT` directly. Use `Promise.all` to run file snapshots concurrently, reducing total wait time for large micro-commits.
